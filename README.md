# Candidate Tracker

Candidate Tracker is a hiring workflow product with a production application, a preserved UI reference app, and supporting product/design context.

## Repo Map

```txt
app/             Production app: React frontend, Fastify API, Prisma/PostgreSQL backend
reference-app/   Runnable UI and product behavior source of truth
final-product-design/ Temporary product contract for backend and workflow decisions
product/         Product development notes, workflow model, screen maps, and analysis
design/figma/    Figma import tooling and downloaded design context
```

## Main Entry Points

- Production app setup and run commands: `app/README.md`
- Current product contract: `final-product-design/README.md`
- Product development trail: `product/README.md`
- Figma import notes: `design/figma/README.md`
- Reference app notes: `reference-app/README.md`
