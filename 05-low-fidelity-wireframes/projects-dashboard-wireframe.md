# Projects Dashboard Low-Fidelity Wireframe

## Screen Name
Projects Dashboard

## Purpose
Let the user select and open one of their projects.

## Layout

```text
+--------------------------------------------------------------+
| Projects                                                     |
| Select a project to continue                                 |
+--------------------------------------------------------------+
|                                                              |
|  +----------------------+   +----------------------+         |
|  | Project Name         |   | Project Name         |         |
|  | Job Position Name    |   | Job Position Name    |         |
|  | Status: Active       |   | Status: Closed       |         |
|  +----------------------+   +----------------------+         |
|                                                              |
|  +----------------------+   +----------------------+         |
|  | Project Name         |   | Project Name         |         |
|  | Job Position Name    |   | Job Position Name    |         |
|  | Status: Active       |   | Status: Active       |         |
|  +----------------------+   +----------------------+         |
|                                                              |
+--------------------------------------------------------------+
```

## Elements
### Header
- Page title: **Projects**
- Subtitle: **Select a project to continue**

### Main Content
- A grid of project cards

### Project Card Contents
Each card contains:
- project name
- job position name
- project status

## Main Interaction
- Clicking a project card opens the Project Pipeline View.

## Design Notes
- This screen is a navigation screen, not a working screen.
- It should remain visually simple and easy to scan.
- No detailed project metrics, notifications, or pipeline summaries should appear here.
