# Product Development

A lean product design pipeline for Token's hiring tracker, ending at wireframes.

## Folder Map

1. `01-product-framing/` — Define what we are building, for whom, and the exact scope boundaries.
2. `02-core-workflow/` — Define the main user journeys and candidate stage progression.
3. `03-information-model/` — Define the core entities, fields, statuses, and relationships needed to support the workflows.
4. `04-screen-map/` — Define the screens required for the MVP, their purpose, and how they connect.
5. `05-wireframes/` — Sketch the structure and layout of the key MVP screens.
6. `06-frontend-analysis/` — Capture the working prototype's routes, roles, behavior, and backend implications.
