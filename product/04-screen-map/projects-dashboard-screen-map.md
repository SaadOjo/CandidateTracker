# Projects Dashboard Screen Map

## 1. Screen Summary
The Projects Dashboard is a simple entry screen that shows the user the projects they are involved in and allows them to open a project.

Its sole purpose is navigation to a project.

## 2. Screen Definition
- **Name:** Projects Dashboard
- **Purpose:** Let users browse and open their projects
- **Primary users:** Hiring Manager, HR
- **Primary action:** Open project

## 3. Main Information Shown
The screen should show a grid of project cards.

Each project card should contain:
- project name
- job position name
- project status

## 4. Main Interaction
- clicking a project card opens that project's main pipeline view

## 5. Navigation Relationship
- Projects Dashboard → Project Pipeline View

## 6. Design Notes
- This screen should stay lightweight and easy to scan.
- It should not become a reporting dashboard.
- It should not show detailed pipeline information.
- It should not include task management or notifications.
- The screen should act as a gateway into a project, not as a working screen.

## 7. Wireframing Priority
This screen should be wireframed for MVP, but it should remain one of the simplest screens in the product.
